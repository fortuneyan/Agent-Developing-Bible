# AI教师Agent - 长期记忆

## 项目概述

AI教师Agent是一个智能备课助手，帮助教师快速生成符合课程标准的教案，支持用户反馈和自动优化。

## 已完成功能

### 3. Web界面 (2026-03-23 新增) ✅

#### 3.1 前端 Vue3 项目
- 路径：`ai_teacher_agent/web/frontend/`
- 技术栈：Vue3 + Vite + Element Plus + ECharts + Socket.io-client + TipTap
- 页面完成情况：
  - 登录页（含演示账号快速填写）
  - 教师端布局（侧边栏 + 顶部导航）
  - 备课工作台（AI生成表单 + 最近教案 + 统计）
  - 教案列表（搜索、筛选、分页）
  - 教案编辑器（TipTap 富文本）
  - 授课教室（WebSocket实时授课、学生列表、聊天）
  - 学情分析（ECharts 成绩分布图 + 雷达图 + 学生详情表）
  - 习题管理（AI生成习题对话框）
  - 学生端（课堂学习、习题练习、学习进度占位）
  - 管理端（用户管理）
- Mock模式：开发环境自动使用 Mock 数据，无需后端即可演示
- 状态管理：Pinia stores（auth/lessonPlan/channel）
- WebSocket composable：`useChannelWS.js`，含自动重连

#### 3.2 后端 FastAPI 项目
- 路径：`ai_teacher_agent/web/backend/`
- 技术栈：FastAPI + asyncpg + JWT + WebSocket
- 已完成：
  - 应用入口 `app/main.py`
  - 认证 API `/api/v1/auth/login`（OAuth2PasswordRequestForm）
  - 教案 API `/api/v1/lesson-plans`
  - 频道 API `/api/v1/channels`
  - WebSocket 端点 `/ws/channel/{channel_id}`（多用户广播）
  - 数据库初始化 SQL `migrations/init_db.sql`

#### 3.3 技术决策
- Mock模式：`USE_MOCK = import.meta.env.DEV`，开发时全走Mock
- ECharts 通过 vue-echarts 集成
- 频道管理器（ChannelManager）内存维护连接状态

### 2. 测试/讲解模块 (2026-03-22 新增)

#### 2.1 数据对象 (4个新对象)
- `Exercise` - 习题数据对象，支持9种题型
- `TestPaper` - 试卷数据对象，支持7种试卷类型
- `TeachingExplanation` - 教学讲解数据对象
- `StudentAnswer`/`TestResult` - 答题记录和结果

#### 2.2 技能实现 (4个新技能)
- `ExerciseGenerator` - 习题生成器
  - 支持9种题型：单选、多选、填空、判断、简答、计算、证明、应用、综合
  - 支持4级难度：容易、中等、较难、挑战
  - 自动生成解析和解题步骤
  
- `TestPaperGenerator` - 试卷生成器
  - 支持7种试卷类型：练习、测验、单元测试、期中、期末、模拟、入学
  - 智能难度分布
  - 试卷结构自定义
  
- `TeachingExplainer` - 智能讲解引擎
  - 概念讲解：从具体到抽象的多步骤讲解
  - 例题讲解：完整的解题思路分析
  - 习题讲解：针对具体题目的讲解
  - 错误分析：针对性纠错讲解
  - 智能问答：回答学生提问
  
- `AnswerEvaluator` - 答题评估器
  - 自动评分：支持多种题型的智能评分
  - 知识分析：知识点掌握度分析
  - 能力分析：多维度能力评估
  - 错题讲解：自动生成错题讲解
  - 学习建议：个性化提升方案

#### 2.3 新增文件
- `src/models/exercise.py` - 习题数据对象
- `src/models/test_paper.py` - 试卷数据对象
- `src/models/teaching_explanation.py` - 讲解数据对象
- `src/skills/teaching_assessment/` - 测试/讲解技能模块
- `assessment_demo.py` - 演示脚本
- `cli_assessment.py` - CLI交互界面

## 技术决策

### 架构设计
- 采用模块化设计，备课模块和测试/讲解模块独立但可集成
- 数据对象使用dataclass，支持序列化和反序列化
- 技能类采用单例模式管理状态

### 扩展性
- 新模块通过独立的skill目录组织
- 数据对象通过__init__.py统一导出
- CLI通过菜单选项集成新模块

#### AI教师Agent项目教训：
- ❌ 需求只说"教师"，未区分角色
- ❌ 未明确Web/CLI交互方式
- ❌ 测试/讲解功能范围模糊
- ✅ 后续补充了TeachingAssessment模块
- ✅ 后续补充了测试/讲解CLI

#### 关键教训：
1. 用户交互方式必须在需求阶段明确（Web/移动端/CLI）
2. 功能边界要清晰，"排除范围"如用户关心应列为"后续版本"
3. 预留扩展接口，Mock服务设计时考虑切换成本
4. 用户角色要细分，不同角色需求差异很大
